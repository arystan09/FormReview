# Synthetic development documents

Exactly 12 examples: six UTF-8 TXT and six digital PDFs. All organizations,
addresses and registration strings are invented. Email domains use example.test.
These documents are public synthetic source assets, not uploaded private files.

labels.provisional.json contains separately authored expectations based on the
scenario text, not results generated by the parser or a model. They are provisional,
unreviewed labels, not independently human-reviewed truth, approval decisions,
or an evaluation claim. Independent human review remains outstanding. The labels
are never read by the application, parser or worker and will not enter model requests.
The provisional `unresolved` term annotation is not a future extraction status.

Cases include complete forms, BOM/decomposed Unicode/CRLF, missing optional values,
ambiguous email/country, non-lexical and out-of-range terms, missing required name,
leading-zero registration identifiers, explicit 0/365 boundaries and untrusted
instructions inside a document. Negative parser fixtures live separately under
fixtures/parser_negative and are not part of the 12 examples.

Regenerate source bytes with `uv run python scripts/generate_fixtures.py`; this
never rewrites labels. PDFs use pypdf and a Base-14 Helvetica font-name reference.
No font file is embedded or distributed and no PDF generator dependency was added.
