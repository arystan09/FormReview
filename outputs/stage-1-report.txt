Prerequisites and exact commands
This machine initially had Python 3.9 but no uv, Python 3.12 or Docker. uv 0.13.9
was downloaded into ignored work/bootstrap; uv downloaded Python 3.12 into work/python.
For this workspace's local bootstrap, first run:
  export PATH="$PWD/work/bootstrap/bin:$PATH"
  export UV_CACHE_DIR="$PWD/work/uv-cache"
  export UV_PYTHON_INSTALL_DIR="$PWD/work/python"
On another machine install uv 0.13.9 and Python 3.12 (or allow uv to fetch Python).
Install Docker Engine with Compose v2 to close container/database gates.

  uv sync --frozen --all-groups
  uv run python manage.py check
  uv run python manage.py help
  uv run ruff check .
  uv run ruff format --check .
  uv run mypy formreview
  uv run pytest -m "not integration and not e2e"
  uv run pytest --collect-only

For the database-backed development quickstart:
  cp .env.example .env
  docker compose up -d db
  uv run python manage.py migrate
  uv run python manage.py runserver 127.0.0.1:8000
In a second terminal:
  curl --fail http://127.0.0.1:8000/health/live

For container verification:
  docker compose config --quiet
  docker build -t formreview:local .
  uv run python scripts/check_container.py
