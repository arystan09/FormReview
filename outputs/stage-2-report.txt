Exact normal quickstart
Prerequisites: Python 3.12, uv 0.13.9, PostgreSQL 18 UTF-8; Docker/Compose v2 for the
commands below and deployment checks. Run from the repository root:
  uv sync --frozen --all-groups
  cp .env.example .env
  docker compose up -d db
  uv run python manage.py migrate
  uv run python manage.py bootstrap_workspace --username reviewer --workspace "Local demo"
  uv run python manage.py runserver 127.0.0.1:8000
In another terminal:
  uv run python manage.py process_jobs
Sign in at http://127.0.0.1:8000/accounts/login, select workspace and upload
 datasets/dev/01_complete.txt or datasets/dev/08_two_pages.pdf.
Refresh the source page after parsing. Upload fixtures/parser_negative/scan_like.pdf
to see no_text_page. Password is prompted; do not put it in shell arguments.
